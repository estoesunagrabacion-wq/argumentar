# Argumentar

App de práctica sobre el texto argumentativo para Prácticas del Lenguaje, 3.er año (Colegio Armenio Arzruni). Tiene teoría, ejercicios de argumentos, conectores, géneros y falacias con corrección, lectura anotada de los textos del cuadernillo, un taller de escritura guiado, la polémica y un desafío final.

Funciona en el navegador y se puede instalar como app (Android, iPhone, computadora). El progreso de cada estudiante se guarda solo en su dispositivo.

Uso exclusivo para la clase.
